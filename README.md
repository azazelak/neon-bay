Neon Bay — an open-world crime game in the spirit of GTA 6, built from scratch in three.js: a neon coastal city to explore on foot and by car, traffic and pedestrians, cars to steal, a wanted level with police who respond, missions and a story, combat, a HUD with a minimap, a start screen and a save.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
